# Hugcode | ติดตามงานทีม

เว็บแอป Kanban ภาษาไทยสำหรับติดตามงานของทีม สร้างด้วย HTML, CSS และ JavaScript ฝั่ง client ใช้ Supabase Auth, PostgreSQL และ Realtime เมื่อกำหนดค่าแล้ว ส่วนบอร์ดตัวอย่างทำงานใน localStorage เพื่อทดลองบนเครื่อง

## เปิดใช้งานในเครื่อง

1. เปิด `index.html` ผ่าน static web server (เช่น Live Server ใน VS Code) หรือ deploy โฟลเดอร์นี้เป็นเว็บไซต์ static
2. หากยังไม่ตั้งค่า Supabase หน้าเริ่มต้นจะแสดงขั้นตอนตั้งค่า กด **ดูบอร์ดตัวอย่างในเครื่อง** เพื่อทดลองโดยไม่เชื่อมต่อทีม ข้อมูลตัวอย่างและการแก้ไขจะอยู่ใน localStorage ของเบราว์เซอร์นั้น
3. เว็บโหลดฟอนต์, Supabase JS และ SheetJS จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อใช้ฟอนต์, เข้าสู่ระบบ และส่งออก `.xlsx`

## ตั้งค่า Supabase

1. สร้างโปรเจกต์ที่ Supabase และเปิด **Authentication → Providers → Email**
2. รัน [supabase/schema.sql](supabase/schema.sql) ใน **SQL Editor** ของโปรเจกต์
3. คัดลอก Project URL และ **publishable key** (หรือ anon key รุ่นเดิม) จาก Project Settings → API แล้วใส่ใน [supabase-config.js](supabase-config.js):

   ```js
   window.HUGCODE_SUPABASE_CONFIG = {
     url: "https://YOUR_PROJECT.supabase.co",
     anonKey: "YOUR_PUBLISHABLE_OR_ANON_KEY"
   };
   ```

4. ห้ามใส่ `service_role` key หรือ secret key ในไฟล์นี้ เพราะเป็นไฟล์ที่ส่งให้เบราว์เซอร์ทุกคนอ่านได้
5. สมัครบัญชีด้วยอีเมลและรหัสผ่านผ่านหน้าเว็บ (หากเปิดยืนยันอีเมล ให้กดยืนยันจากอีเมลก่อนเข้าสู่ระบบ) ผู้ใช้ที่สมัครใน Supabase โปรเจกต์นี้จะเห็นบอร์ดทีมเดียวกัน

ตาราง `public.workboard_state` เก็บบอร์ดร่วมไว้ในแถว `id = 1` โดยคอลัมน์ `state` เป็น JSONB และเปิด RLS ให้อ่าน/เขียนได้เฉพาะผู้ใช้ที่ผ่าน Supabase Auth แล้ว Realtime รับการเปลี่ยนแปลงของแถวดังกล่าว ส่วน localStorage เก็บข้อมูลสำรองและเก็บการแก้ไขที่ยังซิงก์ไม่สำเร็จไว้เพื่อส่งขึ้นเมื่อเชื่อมต่อใหม่

## Deploy บน Vercel

1. นำโฟลเดอร์นี้ขึ้น Git repository หรือ import repository เข้า Vercel
2. เลือก **Other** หรือ static site โดยไม่ต้องใช้ build command; ไฟล์หน้าเว็บอยู่ที่ root
3. กำหนดค่า `supabase-config.js` ให้มี URL และ public publishable/anon key ที่ถูกต้องก่อน deploy (หรือแก้ไฟล์แล้ว redeploy)
4. ใน Supabase Authentication → URL Configuration เพิ่ม URL ของ Vercel เป็น Site URL และ Redirect URL ที่อนุญาต
5. เปิด URL ที่ deploy แล้วสมัครบัญชี/เข้าสู่ระบบ

## ฟีเจอร์

- เพิ่ม แก้ไข ลบ และเปิดดูรายละเอียดงาน พร้อมประวัติความคิดเห็น
- ลากงานระหว่างสถานะ, ใช้เมนูบนการ์ดเพื่อย้ายสถานะหรือลบ
- ค้นหาและกรองตามผู้รับผิดชอบ วันที่มอบหมายตั้งแต่ และกำหนดส่งถึง
- ส่งออกงานที่ตรงกับตัวกรองเป็นไฟล์ Excel `.xlsx`
- จัดการตัวเลือกผู้รับผิดชอบ ผู้มอบหมาย โมดูล และสถานะ
- บอร์ดปรับเป็น 4 คอลัมน์บนจอกว้าง, 2 คอลัมน์บนแท็บเล็ต และคอลัมน์เดียวบนมือถือ
- มีตัวอย่างงานภาษาไทยสำหรับดูหน้าตาและพฤติกรรมของบอร์ด

## ข้อจำกัด

- บอร์ดจัดเก็บเป็น JSONB แถวเดียวและใช้ร่วมกันทั้งโปรเจกต์ Supabase; การเขียนพร้อมกันหลายคนอาจชนกันได้ และการเขียนล่าสุดอาจแทนที่การแก้ไขก่อนหน้าที่ยังไม่ซิงก์
- สิทธิ์เริ่มต้นให้ผู้ใช้ที่ยืนยันตัวตนใน Supabase โปรเจกต์เดียวกันร่วมแก้ไขทั้งบอร์ด ไม่มีบทบาทสมาชิกหรือสิทธิ์แยกโปรเจกต์
- ถ้าเครือข่ายขาดระหว่างแก้ไข ระบบเก็บข้อมูลไว้ใน localStorage และพยายามซิงก์เมื่อมีการแก้ไขอีกครั้งหลังกลับมาออนไลน์; การสำรองนี้ผูกกับเบราว์เซอร์และอุปกรณ์เดิม
- ฟอนต์, Supabase client และ Excel exporter มาจาก CDN; ถ้า CDN ใช้ไม่ได้ ฟอร์ม/บอร์ดในตัวอย่างยังเปิดได้ แต่การยืนยันตัวตนหรือส่งออกไฟล์อาจใช้ไม่ได้
